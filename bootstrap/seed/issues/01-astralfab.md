Root of the AstralFab program: a two-repository family — `astralfab` (the platform, and the family's single issue tracker) and `astralfab-artifacts` (issues off) — governed by doctrine, changed only through reviewed pull requests into `integration`.

This tree carries exactly one dimension: domain of work. Its children are `Governance`, `Repositories`, `Research`, and `Delivery`. Every other facet of a thing (which repository, which stage, provisional or accepted) is a label dimension or a body field, never a fork of this tree.

An issue here is an envelope — scope plus current decision — not an archive. Substance lives in files landed by pull request and is linked from the issue that owns it.
