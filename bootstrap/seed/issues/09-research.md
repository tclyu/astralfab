Container for the knowledge this estate produces and consumes. Children:
`Documentation` (everything documentation, including the convention that makes
research writable) and `Estate` (the facts of this estate and the decisions
derived from them).

The pipeline this container exists to serve: generic research is written and
preserved in the repository first; estate-specific analysis and design build on
it; deliverables (skills, code) follow from design. Every stage's output is a
file landed by pull request under an accepted envelope — research that lives
only in a comment thread or a chat transcript does not exist.

New research subjects get their own single-concept issue in this container when
work on them begins, not before.
